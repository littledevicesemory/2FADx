2FA Dx demos

Companion software for the 2FA Dx printed paper-fluidic card. The card turns a texted key (which valves to punch) into a code that only a real test run reveals. Both demos are built from the card's design files in this repository.

How the card works

Six animated chapters: the layer stack, sample in, punching valves, crossings and vias, the readout, and every key's code.

 Key and verify

A clinic console and a patient's phone. Text a key, run the card on screen, reply with the code and see the clinic verify it.
Source and card files: github.com/littledevicesemory/2FADx. Rebuild with python3 web/build.py.
