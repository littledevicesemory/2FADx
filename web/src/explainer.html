2FA Dx card: from punch to code

How a 3D-printed paper-fluidic card turns a texted key into a code only a test run can reveal. Drawn from the card's own design files.

Geometry, layer thicknesses, vias and codebooks are exported from adherio_gen.py and adherio_print.py (printed mode). The wicking front is computed on a 0.4 mm grid as the shortest path through paper from the sample pad, layers joined only at vias; it reproduces every codebook entry. Schematic: the front's timing (drawn slowing with distance, as Washburn wicking does), the colour of the swatch reaction, the drop and the punch die, and the via cross-section's proportions. Companion app: 2FA Dx key and verify. Source: github.com/littledevicesemory/2FADx.
